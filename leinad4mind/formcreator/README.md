# Form Creator Extension

## Install
1. Download the latest release.
2. In the `ext` directory of your phpBB board, create a new directory named `leinad4mind` (if it does not already exist).
3. Copy the `formcreator` folder to `phpBB/ext/leinad4mind/` (if done correctly, you'll have the main extension class at (your forum root)/ext/leinad4mind/formcreator/composer.json).
4. Navigate in the ACP to `Customise -> Manage extensions`.
5. Look for `Form Creator` under the Disabled Extensions list, and click its `Enable` link.

## Uninstall
1. Navigate in the ACP to `Customise -> Extension Management -> Extensions`.
2. Look for `Form Creator` under the Enabled Extensions list, and click its `Disable` link.
3. To permanently uninstall, click `Delete Data` and then delete the `/ext/leinad4mind/formcreator` folder.
