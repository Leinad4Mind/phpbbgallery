# phpBB Gallery Add-on: Featured Images

Adds a moderator-curated image selection to phpBB Gallery 4.2.0 or newer. The selection can use the configured Gallery card layout or an accessible, responsive slideshow with keyboard, touch and reduced-motion support.

Only moderators with `m_edit` in the image album may add or remove an image. Every viewer receives only approved images they can already access; the add-on never bypasses Gallery permissions, personal-album privacy or visibility policies.

## Requirements

- phpBB 3.3
- PHP 8.1 or newer
- phpBB Gallery Core 4.2.0 or newer

## Installation

Copy the directory to `ext/phpbbgallery/featured`, enable it from **ACP > Customise > Manage extensions**, then configure the block in the Gallery configuration page.
