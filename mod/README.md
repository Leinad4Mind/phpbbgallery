# [MyOOS [Dumper]] 
===============

MyOOS [Dumper] (now phpBBDumper) is an open source community project. MyOOS [Dumper] is a backup programme for MySQL databases. It can be used to create backup copies of data (forum, shop, blog, etc.) and restore them if necessary. MyOOS [Dumper] is a particularly useful alternative for web space without shell access. 

Requirements
------------

- PHP version 8.0.2 or higher.
- MySQL version 5.6 or higher.
- Apache version 2.4 or higher.


Installation
------------

1. download [MyOOS [Dumper] (phpBBDumper)](https://www.phpbb3-support.square7.ch/)
2. unzip the downloaded zip file 
3. unzip the file into an empty directory and upload everything from the phpBBDumper directory to the server
4. call up the file install.php with your browser. The installation routine will guide you through the individual steps and help you to create the access data and the database.
