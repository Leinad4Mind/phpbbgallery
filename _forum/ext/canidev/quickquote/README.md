# cBB QuickQuote Extension

## Install

1. Download the latest release and unzip the package.
2. Upload the content of the 'upload' directory to the 'ext' directory of your forum.
3. Navigate in the ACP to 'Customise -> Manage extensions'.
4. Look for "cBB QuickQuote" under the Disabled Extensions list, and click its 'Enable' link.
6. Set up and configure the extension by navigating in the ACP to 'Extensions -> QuickQuote'.

## Uninstall

1. Navigate in the ACP to 'Customise -> Extension Management -> Extensions'.
2. Look for 'cBB QuickQuote' under the Enabled Extensions list, and click its 'Disable' link.
3. To permanently uninstall, click 'Delete Data' and then delete the '/ext/canidev/quickquote' directory.
