# JV Custom Language

## Quick Install
You can install this on the latest release of phpBB 3.1 by following the steps below:

1. Unzip the downloaded release.
2. Copy the 'jv' directory in the  (your forum root)/ext/) directory.
3. Navigate in the ACP to 'Customise -> Manage extensions'.
4. Look for 'JV Custom Language' under the Disabled Extensions list, and click its 'Enable' link.
5. Set up and configure 'JV Custom Language' by navigating in the ACP to 'Extensions' -> 'JV Custom Language'.

## Update

1. Unzip the downloaded release.
2. Navigate in the ACP to 'Customise -> Manage extensions'.
3. Look for 'JV Custom Language' under the Enabled Extensions list, and click its 'Disable' link.
4. Copy the 'jv' directory in the  (your forum root)/ext/) directory.
5. Navigate in the ACP to 'Customise -> Manage extensions'.
6. Look for 'JV Custom Language' under the Disabled Extensions list, and click its 'Enable' link.
7. Set up and configure 'JV Custom Language' by navigating in the ACP to 'Extensions' -> 'JV Custom Language'.

## Uninstall

1. Navigate in the ACP to 'Customise -> Extension Management -> Extensions'.
2. Look for 'JV Custom Language' under the Enabled Extensions list, and click its 'Disable' link.
3. To permanently uninstall, click 'Delete Data' and then delete the '/ext/jv/customlanguage' directory.
