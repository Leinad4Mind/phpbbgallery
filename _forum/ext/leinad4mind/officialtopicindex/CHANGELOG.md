# Official Topic Index changelog

## 2.0.0 - 2026-08-05

- Restored the official `leinad4mind/officialtopicindex` vendor and migration lineage.
- Incorporated the audited DMZX 2.0 implementation and retained upgrade compatibility with both lines.
- Added CSRF-protected moderator actions, permission-aware batch queries, validation, limits, and safer ACP operations.
- Added after, before, and replace display modes while preserving the 1.0.6 behaviour on upgrade.
- Added a standalone index route, configurable new-topic forum, integration events, tests, and shared templates.
- Fixed the 1.0.6 rollback migration targeting the posts table instead of the topics table.
