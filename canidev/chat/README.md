# cBB Chat Extension

## Quick Install
You can install this on the latest release of phpBB 3.1 by following the steps below:

1. Download the latest release.
2. Unzip the downloaded release.
3. Upload the content of the 'upload' directory to the 'ext' directory of your forum.
4. Navigate in the ACP to 'Customise -> Manage extensions'.
5. Look for "cBB Chat" under the Disabled Extensions list, and click its 'Enable' link.
6. Navigate in the ACP to 'General' and purge the cache.
7. Set up and configure the chat by navigating in the ACP to 'Extensions -> Chat'.

## Uninstall

1. Navigate in the ACP to 'Customise -> Extension Management -> Extensions'.
2. Look for 'cBB Chat' under the Enabled Extensions list, and click its 'Disable' link.
3. To permanently uninstall, click 'Delete Data' and then delete the '/ext/canidev/chat' directory.
